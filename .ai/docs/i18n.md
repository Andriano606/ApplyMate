# i18n Conventions

Default locale is **Ukrainian (`uk`)**. Both `config/locales/uk.yml` and `config/locales/en.yml` must be kept in sync.

- Always use the full `I18n.t()` form — never the `t()` Rails helper shorthand.
- Never use `default` params: I18n.t('vacancy.search.or', default: 'OR')

## Namespace Structure

Top-level keys match the concept name in snake_case:

```
uk:
  activerecord:  # Rails model error messages
  admin:         # admin namespace (api_token, proxy, source, dashboard, ...)
  components:    # shared UI components
  home:
  navbar:
  saved_filter:
  session:
  simple_form:
  vacancy:
```

## Key Naming Conventions

### CRUD operation flash messages

```yaml
saved_filter:
  create:
    success: Фільтр збережено
  update:
    success: Фільтр оновлено
  destroy:
    success: Фільтр видалено
    confirm: Видалити збережений фільтр?
```

Used in operations: `notice(I18n.t('saved_filter.create.success'))`

### Form field labels

```yaml
saved_filter:
  new:
    form:
      name: Назва фільтру
      name_placeholder: напр. Embedded remote
```

Used in Slim templates: `= f.input :name, label: I18n.t('saved_filter.new.form.name')`

### Index page — table headers

```yaml
admin:
  api_token:
    index:
      title: API токени
      empty: Токени ще не створені
      new: Створити токен
      table:
        name: Назва
        user: Користувач
        created_at: Створено
        actions: Дії
```

### Enum status labels

Pattern for a model enum (generic `widget` example — no enum labels exist in the locale files right now):

```yaml
widget:
  status:
    draft: Чернетка
    published: Опубліковано
```

Used in views: `I18n.t("widget.status.#{widget.status}")`

### Nested sections within a form

```yaml
admin:
  widget:
    form:
      pagination:
        title: Пагінація
        url_template: Шаблон URL
```

### New / Edit page titles and submit buttons

```yaml
admin:
  source:
    new:
      title: Нове джерело
      submit: Додати джерело
    update:
      title: Редагувати джерело
      submit: Оновити джерело
```

## Ukrainian Pluralization

Ukrainian requires four plural forms. Use `one`/`few`/`many`/`other`:

```yaml
vacancy:
  search:
    results_count:
      one: "Знайдено %{count} вакансію"
      few: "Знайдено %{count} вакансії"
      many: "Знайдено %{count} вакансій"
      other: "Знайдено %{count} вакансій"
```

Call: `I18n.t('vacancy.search.results_count', count: n)`

## Workflow for Adding New Keys

1. Add to `uk.yml` first (it is the source of truth).
2. Add the same key to `en.yml` with an English value.
3. Run `bundle exec i18n-tasks missing` to find any keys present in one locale but not the other.
4. Run `bundle exec i18n-tasks unused` periodically to clean up orphaned keys.
